# Cardiovascular Disease Prediction

## About the Project
This project explores the use of machine learning to predict the presence of cardiovascular disease using health-related data.

## Objectives
- Understand and prepare a dataset for machine learning.
- Train and evaluate machine learning models.
- Compare model performance using evaluation results.
- Learn the practical workflow of a machine learning project.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib

## Project Workflow
1. Load and explore the dataset.
2. Perform data preprocessing.
3. Train machine learning models.
4. Evaluate and compare model performance.
5. Review the results and identify possible improvements.

## Project Files
- `Cardiovascular_Disease_Prediction.ipynb` — notebook containing the project code and analysis.
